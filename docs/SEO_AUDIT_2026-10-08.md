# Auditoría SEO — Delicias Urbanas

**Fecha:** 8 de octubre de 2026
**Dominio:** https://deliciasurbanas.com.ar/
**Hosting:** GitHub Pages, rama principal main.
**Alcance:** SEO técnico, contenido de la página única, SEO local, datos estructurados, imágenes, accesibilidad y preparación de producción.

## Resumen de hallazgos y cambios

| Tema | Estado inicial | Acción |
|---|---|---|
| Publicación | Workflow copiaba solo CSS, JS y recursos antiguos; el rediseño habría quedado roto. | Nuevo build detecta las 18 entradas CSS/JS reales del HTML y solo publica recursos públicos. |
| Menú indexable | Productos ausentes del HTML inicial, dependientes de JavaScript. | Generación en cada deploy de 29 productos activos agrupados en 4 categorías, visibles también sin JavaScript. |

| Logo público | PNG de aproximadamente 293 KB. | WebP de 45 KB (85% menos), conservando favicon y original. |
| Rastreo | Robots y sitemap correctos, sin fecha de modificación. | Sitemap generado con fecha del deploy; una URL canónica para la página única. |

| UX y navegación | Diseño local con anclas, filtros y carrito. | QA escritorio/celular sin desbordamiento con pedidos simulados. |

## Verificaciones

- Home, robots.txt y sitemap.xml respondían HTTP 200 en el dominio principal; admin.html y URL inexistente respondían HTTP 404.
- GitHub Pages informa dominio deliciasurbanas.com.ar con HTTPS exigido.
- Sin JavaScript: 29 productos y 4 secciones, con JSON-LD que incluye los mismos precios y nombres.
- Revisados sintaxis JavaScript, archivos públicos, canonical, descripción, títulos, robots, sitemap e imagen social.
- Probado flujo de categorías, personalización y carrito en 1440, 375 y 320 px y modo de movimiento reducido.
- La publicación se verificará por separado después del despliegue, incluyendo recursos, dominio y funcionalidades.

## Pendientes externos

1. **Host www:** www.deliciasurbanas.com.ar resuelve hacia GitHub Pages, pero devolvió un error TLS. El dominio principal con HTTPS responde. Revisar cobertura del certificado y redirección al host canónico; no se modificó DNS sin acceso a la zona.
2. **Google Search Console:** la confirmación de indexación, consultas, cobertura, impresiones y envío del sitemap requiere acceso verificado.
3. **Perfil de Empresa de Google:** verificar que dirección, horario, teléfono, enlace y categorías coincidan con la web. No se modificó la ficha externa.
4. **Core Web Vitals de campo:** precisan Search Console o CrUX. El ahorro de bytes y las pruebas locales no equivalen a una puntuación Lighthouse ni a un ranking garantizado.
5. **Actualizaciones comerciales:** cada despliegue de catalog.json regenera el HTML del menú y su JSON-LD, evitando inconsistencias entre productos y precios.

## Repetir los controles

Ejecutar en la raíz: npm run check, npm run build y npm run check:seo.

El directorio _site/ es generado y excluido de Git. GitHub Actions construye nuevamente la versión pública y solo la publica si sus controles pasan. El panel administrativo local y el servidor Node no forman parte del artefacto público.
